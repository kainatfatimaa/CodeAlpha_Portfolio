# CodeAlpha_Portfolio

A clean, modern, and responsive professional portfolio website built using pure HTML, CSS, and JavaScript. This project showcases my academic journey, technical skills, core software engineering projects, and contact information.

## ✨ Features
- **Dynamic Theme Switcher:** Seamlessly toggles between Light Mode and Dark Mode.
- **Fully Responsive Layout:** Optimized for desktops, tablets, and mobile screens.
- **Interactive Navigation:** Smooth scrolling sections with an active-link tracker and a mobile-friendly hamburger menu.
- **Scroll Reveal Animations:** Elegant fade-in animations as the user scrolls through content.
- **Functional Contact Form:** Built-in form validation and submission simulation.

## 🛠️ Tech Stack & Skills
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Design & Typography:** Google Fonts (Inter, Fira Code), Font Awesome Icons
- **Core Technical Fields:** Data Structures & Algorithms, Object-Oriented Programming (OOP), Database Management (MySQL)
